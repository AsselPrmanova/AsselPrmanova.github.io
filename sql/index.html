📊 Key Analysis

Customer activity analysis using SQL queries.

SELECT id_client,
COUNT(DISTINCT DATE_FORMAT(date_new, '%Y-%m')) AS active_months
FROM transactions
GROUP BY id_client;

💰 Revenue Insights

Monthly spending distribution by gender.

SELECT DATE_FORMAT(t.date_new, '%Y-%m') AS month,
c.gender,
SUM(t.sum_payment) AS total_spend
FROM transactions t
JOIN customers c ON t.id_client = c.id_client
GROUP BY month, c.gender;
